## المرحلة الأولى: بناء ملف AAB/APK

### المتطلبات الأساسية

قبل البدء، تأكد من توفر الآتي على جهازك:

```bash
# 1. تثبيت Node.js (v18 أو أحدث)
node --version  # يجب أن يظهر v18+

# 2. تثبيت EAS CLI
npm install -g eas-cli

# 3. تسجيل الدخول لحساب Expo
eas login
# أدخل: almhbob2026
```

### خطوات بناء الـ AAB (للنشر على Google Play)

```bash
# 1. استنسخ المستودع
git clone https://github.com/almhbob/ahbaballah-kindergarten.git
cd ahbaballah-kindergarten

# 2. ثبّت المكتبات
npm install

# 3. أضف متغيرات البيئة (Firebase)
# أنشئ ملف .env.local وأضف المتغيرات

# 4. بناء AAB للنشر على Google Play
eas build --platform android --profile production

# 5. بناء APK للاختبار المباشر
eas build --platform android --profile preview
```

### ملف eas.json المطلوب

أنشئ هذا الملف في جذر المشروع:

```json
{
  "cli": {
    "version": ">= 12.0.0",
    "appVersionSource": "local"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "preview": {
      "distribution": "internal",
      "android": {
        "buildType": "apk"
      }
    },
    "production": {
      "android": {
        "buildType": "app-bundle"
      }
    }
  },
  "submit": {
    "production": {
      "android": {
        "serviceAccountKeyPath": "./google-service-account.json",
        "track": "internal"
      }
    }
  }
}
```

---

تطبيق **نظم إدارة رياض الأطفال** هو نظام إدارة متكامل مصمم خصيصاً للروضات والمدارس الخاصة، يربط بين الإدارة والمعلمين وأولياء الأمور في منصة واحدة سهلة الاستخدام.

**🏫 بوابة الإدارة:**
- لوحة تحكم شاملة بالإحصائيات اليومية
- إدارة بيانات الطلاب كاملاً
- إدارة الموظفين والرواتب والحضور
- إدارة الأخبار والإعلانات
- التقويم المدرسي والفعاليات
- النقل المدرسي والمسارات
- معرض الصور والذكريات
- التسجيل الإلكتروني للطلاب الجدد

**👩‍🏫 بوابة المعلمة:**
- قائمة الطلاب حسب المستوى
- تسجيل الحضور والغياب
- رصد الدرجات والسلوك والواجبات
- الجدول الدراسي اليومي
- التواصل مع الإدارة وأولياء الأمور

**👨‍👩‍👧 بوابة ولي الأمر:**
- متابعة أداء الطفل يومياً
- التقارير اليومية (المزاج، الغذاء، التعلم)
- درجات الطفل وحضوره وسلوكه
- لوحة الشرف والمكافآت
- متابعة الرسوم الدراسية
- التواصل المباشر مع الإدارة

**✨ مزايا التطبيق:**
✅ واجهة عربية كاملة بتصميم أنيق
✅ مزامنة فورية عبر الإنترنت (Firebase)
✅ يعمل بدون اتصال (وضع أوفلاين)
✅ دخول بالبصمة أو رمز PIN
✅ تعدد المستخدمين بأدوار مختلفة
✅ تخصيص هوية الروضة البصرية
✅ تقارير شاملة وإحصائيات دقيقة
✅ آمن ومشفر بالكامل

```

3. صفحة الطالب (بياناته الكاملة)
4. التقرير اليومي (من بوابة المعلمة)
5. واجهة ولي الأمر (متابعة الطفل)
6. لوحة الشرف (الأيقونات والمكافآت)
7. معرض الصور
8. التقويم والفعاليات
```
